# Limicelia
A personal project showcasing creative works and ideas.

This repository contains a collection of HTML files and images that demonstrate various creative projects and ideas. The main entry point is `index.html`, which provides a gateway to explore the different sections of the site.

## Key Features
* A personal website showcasing creative works and ideas
* Multiple HTML files for different sections, including a blog and resources

## Installation/Setup
No installation or setup is required, as this is a static website.

## Usage
Simply open `index.html` in a web browser to explore the site.

## Tech Stack
* HTML for structuring content
* Python (not actively used in this repository)
